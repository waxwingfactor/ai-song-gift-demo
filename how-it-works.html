How the song automation works

A working demo of the personalized-song workflow: quiz → AI lyrics → customer edits → Shopify payment → Kie.ai music → private storage → email delivery, with an operations dashboard. Ribbon & Rhyme is a fictional brand; checkout runs on a Shopify development store with test payments.

Architecture

Existing platforms only. No servers to maintain: n8n runs the workflow, Supabase keeps the order state and the audio, Shopify takes the money, Kie.ai writes the lyrics (Claude) and the music (Suno V6).

Safeguards against duplicates and wasted spend

Pay first, generate secondNothing is sent to Kie.ai until Shopify confirms payment. Abandoned carts cost one lyrics draft (~$0.03), never a song.
One payment, one songA row lock plus unique keys on the Shopify order ID and the Kie.ai task ID. Shopify's retries, double clicks and replayed webhooks are logged and ignored.
Second payment for the same songFlagged for a refund in the dashboard and emailed to the team; never generated twice.
Signed webhooksShopify deliveries are checked with HMAC-SHA256 over the raw body. Kie.ai callbacks aren't trusted at all: the result is re-read from Kie.ai's API before anything is stored.
Spend capsLyrics: 3 drafts per song, 8 songs per visitor per day, 30 drafts an hour in total. Music: a daily generation cap parks extra orders for one-click approval.
Amount checkAn order that paid less than the price (discount abuse, wrong product) is held for review instead of generated.
No stuck ordersIf a callback never arrives, the watchdog checks Kie.ai at 8 and 20 minutes and finishes or fails the order. Max 3 attempts per order.
AlertsAny failed step, crashed workflow, held or suspicious order emails the team with a link to the execution.

Admin visibility

The team dashboard (access key) shows every order with its status, a step-by-step timeline (quiz → draft → approved → paid → sent to Kie.ai → stored → emailed), the exact lyrics and musical direction sent, the customer's quiz answers, what each order cost, alerts, and API spend by service. Buttons: retry generation, check Kie.ai now, resend email, cancel. n8n's own execution log keeps every run for deeper debugging.

What gets handed over

  • 9 importable n8n workflows: song API, Shopify orders, Kie.ai callback, submit/finish/email/alert sub-workflows, admin actions, error alerts.
  • One Supabase SQL file: tables, state-change functions, permissions, private bucket.
  • The quiz, song page and dashboard (plain HTML/JS, no build step); can also live inside a Shopify theme page.
  • Setup guide (accounts, keys, webhook, test checkout), runbook for failures and refunds, and a cost sheet.
